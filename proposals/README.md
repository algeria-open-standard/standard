# Les propositions

Chaque changement de sorte B à E passe par une proposition ([la
méthode](../process/README.md)). Elles restent toutes ici, acceptées ou non :
c'est la mémoire des décisions du standard.

| N° | Titre | Sorte | État |
| --- | --- | --- | --- |
| 0000 | [Modèle de proposition](0000-modele.md) | | |

Ce qui a précédé la méthode, le socle 0.1, les cachets 0.1, la confiance 0.1 et
le format `.hr` 0.1, est entré comme premier état du dépôt, à l'état de
brouillon. Leur passage à l'état candidat suivra la méthode.
